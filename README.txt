Demon Slayer Showcase - run locally
1. Unzip the folder and keep everything together (index.html, style.css, script.js, images/, video/).
2. Double-click index.html to open it in Chrome, Edge, Firefox or Safari.
   (The GSAP animation library loads from a CDN, so you need an internet connection the first time.)
Optional local server: open a terminal in this folder and run  python -m http.server 8000  then visit http://localhost:8000
